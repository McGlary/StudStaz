# StudStaž — каталог стажировок и вакансий (Лабораторная работа №2)

Динамическое интерактивное веб-приложение (Single Page Application — SPA), разработанное на чистом JavaScript (Vanilla JS). Проект является прямой модернизацией статического макета из Лабораторной работы №1.

## О проекте
Платформа для студентов и начинающих IT-специалистов, позволяющая просматривать, фильтровать и добавлять предложения о стажировках и первой работе. Приложение управляет состоянием на стороне клиента и сохраняет данные локально в браузере пользователя.

## Реализованный функционал
В рамках лабораторной работы реализованы следующие ключевые возможности:
1. **Динамический поиск:** Фильтрация карточек в реальном времени по названию, компании или навыкам (без учета регистра).
2. **Фильтрация:** Выбор формата работы (удалённо, в офисе, гибрид) с возможностью сброса.
3. **Сортировка:** IMMUTABLE-сортировка массива данных по алфавиту (А–Я / Я–А) и по дате добавления (сначала новые).
4. **Модальное окно:** Всплывающая форма для добавления новой вакансии. Закрывается по крестику, кнопке «Отмена», клику на затемнённый фон (backdrop) или клавише `Escape`.
5. **Клиентская валидация:** Проверка полей формы через Constraint Validation API (`input.validity`) с выводом понятных текстовых ошибок под каждым невалидным полем.
6. **Делегирование событий (Event Delegation):** Обработка кликов по кнопкам «Удалить» через единый слушатель на родительском контейнере с использованием `e.target.closest()`.
7. **Постоянство данных (Data Persistence):** Автоматическое сохранение и загрузка массива вакансий через `localStorage` (с использованием `JSON.stringify` / `JSON.parse`). При первом запуске загружаются демонстрационные данные.
8. **Архитектура State-Driven UI:** Интерфейс полностью перерисовывается функцией `render()` на основе единого объекта состояния `state`, без прямого манипулирования DOM вне этой функции.
