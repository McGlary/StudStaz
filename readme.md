# StudStaž — каталог стажировок и вакансий

Учебный проект по веб-разработке лабораторная работа №1.
Статическая страница-каталог стажировок для студентов и начинающих
IT-специалистов. Данные пока хранятся прямо в HTML;
JavaScript, сервер и база данных будут добавлены в следующих лабораторных.

## Для кого
Студенты и выпускники, которые ищут первую стажировку или работу в IT.

## Блоки страницы
- Шапка с названием проекта и навигацией;
- Главный заголовок и описание задачи проекта;
- Форма поиска (ключевое слово + формат работы);
- Каталог из 6 карточек: название, компания, описание и свойства (направление, формат, навыки);
- Раздел «О проекте» с инструкцией;
- Подвал с контактами.

## Как открыть
1. Клонировать репозиторий.
2. Открыть файл `server_start.bat` двойным кликом. НЕ ВИРУС!

## Структура
- `index.html` — главная страница;
- `styles/main.css` — стили;
- `assets/videos/` — видео карточек

## Видео
Видео взяты с бесплатных стоков ...
Если файл отсутствует, вместо видео показывается серая заглушка, страница не ломается.
